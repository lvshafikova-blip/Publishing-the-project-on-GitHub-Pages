# Mickey Mouse «Мышь Микки Маус»
:---: **Микки Маус** — антропоморфный мышонок, один из символов компании *The Walt Disney Company* и американской поп-культуры в целом. Он стал одним из самых узнаваемых персонажей в мире, а его образ ассоциируется с добротой, любопытством и приключениями.

## История создания

Микки Маус появился в 1928 году после того, как Уолт Дисней потерял права на своего первого популярного персонажа — кролика Освальда. Идея создания нового героя возникла во время четырёхдневной поездки Диснея на поезде. Изначально персонажа хотели назвать Мортимер Маус, но жена Диснея Лилиан посчитала это имя слишком высокомерным, и в итоге появилось имя Микки.
